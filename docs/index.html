02 — How I work

Forward deployed, not slide-decked.

  1. Discover

    Sit with the operators. Map the workflow they already run, including the ugly exceptions.

  2. Prototype on their stack

    Azure, Bedrock, Ollama, UiPath, PAD — I meet the estate. Greenfield is a last resort.

  3. Evaluate

    If it cannot be scored, it cannot be handed off. Tests, evals, and failure modes before polish.

  4. Handoff

    Something the team will run on Monday. Docs, guardrails, and a path to own it without me.
